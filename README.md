# 학년 마무리 퀴즈 (초등 1~6학년)

Neon(DB) + Netlify(호스팅/Functions) + GitHub(배포 연동)으로 동작하는 학년 마무리 퀴즈 앱입니다.

```
public/                     학생 화면(index.html) · 관리자 화면(admin.html) · css/js
public/templates/           문항 업로드용 엑셀 양식 (question_template.xlsx)
netlify/functions/          API (학생 3개, 관리자 5개, 설정 1개)
netlify/lib/                공통 로직(학급 규칙, 출제, 엑셀 행 검증, 토큰, DB)
db/schema.sql               Neon에서 실행할 테이블 생성/업그레이드 SQL
db/seed_sample.sql          (선택) 테스트용 샘플 문항 30개
tests/                      node:test 테스트 (npm test)
```

## 설정 순서

### 1) Neon
1. Neon 프로젝트의 **SQL Editor**에서 `db/schema.sql` 전체를 실행합니다.
   - 이전 버전의 스키마를 이미 실행했다면 **같은 파일을 다시 실행**하면 새 컬럼/테이블이 추가됩니다.
2. (선택) 테스트용 샘플 문항이 필요하면 `db/seed_sample.sql`도 실행합니다.
3. 연결 문자열(`postgresql://...?sslmode=require`)을 복사해 둡니다.

### 2) GitHub
이 폴더를 저장소로 올립니다. (**관리자 코드가 코드에 들어 있으므로 저장소는 비공개(Private)를 권장합니다.**)

### 3) Netlify
저장소를 연결(Import from Git)한 뒤 **Environment variables**를 등록합니다.

| 이름 | 설명 |
|---|---|
| `DATABASE_URL` | Neon 연결 문자열 (필수) |
| `TOKEN_SECRET` | 16자 이상 임의 문자열 (필수, 토큰 서명용) |
| `ADMIN_CODE` | 관리자 코드. **없으면 기본값 `0227`** |

배포 후 학생은 `/`, 관리자는 `/admin`으로 접속합니다.

## 동작 규칙

### 학생
1. 학년 선택 → 반/번호 선택(확인 문구 표시) → 번호 확인
2. **퀴즈 종류 선택: 넌센스 퀴즈 / 일반 퀴즈** (학생이 직접 고름, 준비되지 않은 쪽은 "준비 중"으로 눌러지지 않음)
3. 5초 안내 후 5문제 시작
   - 일반 퀴즈: 객관식 3 + OX 2, 교과가 섞여 출제
   - 넌센스 퀴즈: **모든 학년 공통** 넌센스 문제 중 무작위 5문제 (객관식/OX 섞임)
4. **어느 쪽이든 5문제를 모두 맞히면 수료** → **수료 완료** 화면 (정답은 제출 후 서버가 채점하며, 풀이 중에는 알려 주지 않음)
5. 수료 완료 화면과 "틀렸어요!" 화면 모두 **5초 뒤 자동으로 첫 화면(학년 선택)** 으로 이동하고, **"지금 처음 화면으로" 버튼**으로 바로 이동할 수도 있습니다.

### 재참여 규칙
- **수료하지 못한 학생**(미수료, 풀이 중 이탈 포함)은 승인 없이 **몇 번이든 다시 도전**할 수 있습니다. 도전할 때마다 새 문제가 출제되고(일반/넌센스는 매번 다시 고를 수 있음), 관리자 화면에 도전 횟수가 표시됩니다.
- **한 번이라도 수료한 학생**은 일반이든 넌센스든 다시 참여할 수 없으며, 관리자가 **재참여 승인**(수료 기록 해지)을 해야 합니다.

### 관리자 (`/admin`)
- 로그인 화면과 관리 화면 위쪽에 **"첫 화면으로"** 버튼이 있어 학생 첫 화면으로 돌아갈 수 있습니다.
- **로그인**: 관리자 코드만 입력합니다. 코드는 `ADMIN_CODE`로 더 길게(영문+숫자 8자 이상) 바꾸는 것을 권장합니다.
  - **로그인 실패는 기기마다 따로** 셉니다. 최근 5분 안에 같은 기기에서 10번 틀리면 그 기기만 5분간 막히고, 다른 기기는 그대로 로그인할 수 있습니다. 7번째 실패부터는 남은 횟수가 화면에 안내되고, 막히면 몇 분 뒤에 다시 시도할 수 있는지 알려 줍니다. 로그인에 성공하면 그 기기의 실패 횟수는 0으로 돌아갑니다.
  - 기기는 브라우저가 처음 접속할 때 만들어 저장해 두는 임의 번호로 구분합니다. 이 번호는 사용자가 바꿀 수 있으므로, 번호를 계속 바꿔 가며 대입하는 것을 막기 위해 **같은 네트워크(IP)에서 나온 실패의 합계가 5분에 30번**을 넘으면 그 네트워크도 5분간 막습니다. (학교처럼 여러 기기가 IP를 공유해도 불편하지 않도록 넉넉하게 잡은 값)
  - 실패 기록 테이블에 기기/네트워크 칸이 필요한데, 예전 DB는 로그인 함수가 처음 실행될 때 자동으로 칸을 추가합니다. (`db/schema.sql`을 다시 실행해도 됩니다)
- **수료 현황**: 학년 탭 → 학급 탭(1·2·4학년 5개 반 / 3·5·6학년 4개 반) → 1~30번 격자. 학년/반/번호로만 표시됩니다. 번호를 누르면 상세를 보고, 수료한 번호는 **재참여 승인**을 할 수 있습니다.
- **문항 관리**: ① 구분(일반 퀴즈/넌센스 퀴즈) → ② 학년(일반 퀴즈만) → ③ 형식(객관식/OX) → ④ 문제 입력 순서로 하나씩 추가하거나, **엑셀로 한 번에** 올릴 수 있습니다.
  - **등록된 문항**은 한 쪽에 5개씩 보이고, **◀ 이전 / 다음 ▶** 로 넘기면서 문항마다 **삭제** 버튼으로 지울 수 있습니다. (삭제 전에 문제 내용을 확인하는 창이 뜨고, 삭제하면 쪽 수가 자동으로 맞춰집니다.)
  - 일반 퀴즈를 열려면 학년마다 **OX 2개 + 객관식 3개 이상**, 넌센스 퀴즈를 열려면 (학년과 상관없이) **넌센스 5개 이상**이 필요합니다. 부족하면 문항 목록 위에 안내가 표시됩니다.
  - '등록된 문항'은 1~6학년 탭(일반 문항)과 **넌센스(공통) 탭**으로 나뉘어 보이고, **최근에 만든 문항이 맨 앞**에 나옵니다. (엑셀로 한 번에 올린 문항은 같은 묶음 안에서 엑셀에 적은 순서대로 보입니다.)
- 학급/번호는 1~6학년 각 30번까지만 허용하고 그 밖의 번호는 서버가 거부합니다.

### 엑셀 일괄 업로드
1. `엑셀 양식 내려받기` → `문항` 시트의 2행부터 한 줄에 문제 1개씩 입력 (작성 방법은 같은 파일의 `작성방법` 시트)
2. 파일을 선택하면 **자동으로 검사**하고 오류 행 번호를 알려 줍니다.
3. 오류가 없으면 `이대로 등록하기`. **한 줄이라도 오류가 있으면 전체가 등록되지 않습니다.** (최대 500행)

| 열 | 입력 |
|---|---|
| 학년 | 일반(정규) 문제는 1~6, 넌센스 문제는 비움 (모든 학년 공통) |
| 구분 | 정규(=일반) / 넌센스 (비우면 정규) |
| 유형 | 객관식 / OX |
| 교과 | 정규(일반)는 필수(목록 선택), 넌센스는 비워도 됨 |
| 문제 | 300자 이내 |
| 보기1~4 | 객관식만, 서로 다른 내용 |
| 정답 | 객관식 1~4 / OX는 O 또는 X |

> 엑셀 읽기는 브라우저에서 SheetJS를 jsDelivr(실패 시 unpkg)로 불러와 처리합니다. 학교 네트워크에서 두 주소가 모두 막혀 있으면 업로드만 동작하지 않고, 하나씩 입력하는 기능은 그대로 사용할 수 있습니다.

### 넌센스 퀴즈
- 문항 관리에서 구분을 **넌센스**로 등록합니다. (객관식/OX 모두 가능, 교과 없음)
- 넌센스 문제는 **학년과 상관없이 모든 학년이 함께 쓰는 공통 문제**입니다. (학년 선택 없이 등록, 엑셀에서는 학년 칸을 비움)
- 전체 **5개 이상** 등록하면 모든 학년 학생이 "넌센스 퀴즈"를 고를 수 있습니다. 5개 미만이면 "준비 중"으로 표시됩니다.
- 학생이 고르면 공통 문제 중 **무작위 5문제**가 나오고, **일반 퀴즈와 똑같이 모두 맞히면 수료**입니다.
- 내부적으로는 DB의 `grade` 칸이 비어 있을 수 없어 넌센스 문항을 `1`로 저장하지만, 출제할 때는 이 값을 보지 않습니다. 같은 문제가 여러 번 등록돼 있어도 한 번만 출제됩니다.

### 태블릿 사용
- 화면 폭(휴대폰/태블릿)에 맞춰 버튼과 글자 크기가 커지도록 만들었습니다. 태블릿에서는 번호 버튼이 한 줄에 10개씩 보이고, 두 번 탭해도 화면이 확대되지 않습니다.
- 학생용 태블릿은 `/`, 관리자는 `/admin`을 열면 됩니다. (가로/세로 모두 사용 가능)

## 로컬 실행 / 테스트
`.env`에 환경변수를 적고 `npm install && npx netlify dev` · 테스트는 `npm test`
